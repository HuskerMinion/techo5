Echo project comparison

People often ask how the projects that bring Echo devices and other screens to Home Assistant compare. This page lists what each one covers. It isn't a ranking: each project is good work with its own focus, and the right one depends on your devices and what you want from them.

This page is kept by TECHO5's author, so read it with that in mind. To keep it even, it was built the same way for every project, TECHO5 included: a separate reviewer for each project read only that project's public repos and listed every feature, the rows come from all six lists, and each answer was checked by a second reviewer. Every cell shows only what each project's own GitHub repos say, plus, for devices, what users report in its issues and discussions (the note says so). Reports elsewhere (Reddit, Discord, forums) aren't counted, and nothing here was tested by me. Not found means nothing was found there, not that it can't work.

Not sure where to start? Answer a few questions about your devices and what you want, and see which projects fit.
